# Pinless Pay Agent Portal

Interactive Pinless Pay agent portal prototype.

## Stack

- React 19
- Vite
- shadcn/ui component architecture
- Radix UI primitives
- Lucide icons
- Existing Pinless Pay visual theme and branding

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Routes

- `/login`
- `/forgot-password`
- `/dashboard`
- `/merchants`
- `/merchant-details`
- `/applications`
- `/application-details`
- `/residuals`

Legacy `.html` URLs redirect to the React routes.
